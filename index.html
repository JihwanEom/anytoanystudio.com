A study note worth keeping

다시 꺼내 보는 학습 노트

Opt-in summaries and vocabulary explained in context, each linked to the subtitle line it came from. Only the video's subtitle text is sent, never audio or video.

선택형 요약과 문맥 속 어휘 설명을 원래 자막 줄에 연결합니다. 영상의 자막 텍스트만 보내고 음성·영상은 보내지 않습니다.

Study Notes · Claude API 학습 노트 · Claude API

From a talk to notes you can replay.

영상 한 편이, 다시 볼 수 있는 노트로.

Open the player menu, review exactly what will be sent, and SubLive asks Claude for a summary and vocabulary notes. Every item links to the subtitle where it appears, so one tap takes you back to that moment.

플레이어 메뉴에서 학습 노트를 열고, 보낼 내용을 확인하면 SubLive가 Claude로 요약과 어휘 노트를 만듭니다. 모든 항목이 해당 자막에 연결되어, 한 번 누르면 그 장면으로 돌아갑니다.

  • Off by default; you review the lines and characters before anything is sent
  • Only subtitle text leaves the device, never audio or video
  • Claude Haiku 5.5 via our server, so no API key ships in the app
  • Notes that do not match a real subtitle line are dropped, not shown
  • 기본값은 꺼짐, 보내기 전에 자막 줄 수와 글자 수를 확인
  • 기기 밖으로 나가는 것은 자막 텍스트뿐, 음성·영상은 보내지 않음
  • 자체 서버를 거쳐 Claude Haiku 5.5 호출, 앱에는 API 키가 없음
  • 실제 자막 줄과 맞지 않는 노트는 보여 주지 않음

How we build 만드는 방식

Three principles, every release.

모든 릴리스에 지키는 세 가지 원칙.

On-device first

기기 안에서 먼저

Speech recognition and translation run on the phone. No upload, no waiting on a server, and subtitles work offline.

음성 인식과 번역을 휴대폰 안에서 처리합니다. 업로드도, 서버 대기도 없고, 자막은 오프라인에서도 동작합니다.

Private by default

기본값은 프라이버시

No accounts, no ads, no tracking. Any cloud feature will be opt-in and clearly labeled.

계정, 광고, 추적이 없습니다. 클라우드 기능은 사용자가 직접 켜야만 동작하고, 명확하게 표시합니다.

Every language

모든 언어를 위해

Built for real multilingual use, from subtitle line breaks in Korean and Japanese to an interface in 21 languages.

한국어·일본어 자막 줄바꿈부터 21개 언어 인터페이스까지, 실제 다국어 사용을 기준으로 만듭니다.

About 소개

A one-person studio from Korea.

한국의 1인 소프트웨어 스튜디오.

AnyToAny Studio was founded by Jihwan Eom on March 1, 2026, as a bootstrapped sole proprietorship in South Korea. SubLive is our first product. It is in development and has not launched on the App Store yet.

엄지환이 2026년 3월 1일 대한민국에서 개업한 1인 개인사업자로, 외부 투자 없이 운영합니다. 첫 제품 SubLive는 개발 중이며 아직 App Store에 출시하지 않았습니다.

We build SubLive with Claude Code. Subtitles and translation run on-device with Apple's frameworks. The optional Study Notes feature calls the Claude API through our own server; it works in our development build and is not released yet.

SubLive는 Claude Code로 개발합니다. 자막과 번역은 Apple 프레임워크로 기기에서 처리합니다. 선택 기능인 학습 노트는 자체 서버를 거쳐 Claude API를 호출하며, 개발 빌드에서 동작하고 아직 출시하지 않았습니다.
