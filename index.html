How we build 만드는 방식

Three principles, every release.

모든 릴리스에 지키는 세 가지 원칙.

On-device first

기기 안에서 먼저

Speech recognition and translation run on the phone. No upload, no waiting on a server, and subtitles work offline.

음성 인식과 번역을 휴대폰 안에서 처리합니다. 업로드도, 서버 대기도 없고, 자막은 오프라인에서도 동작합니다.

Private by default

기본값은 프라이버시

No accounts, no ads, no tracking. Any cloud feature will be opt-in and clearly labeled.

계정, 광고, 추적이 없습니다. 클라우드 기능은 사용자가 직접 켜야만 동작하고, 명확하게 표시합니다.

Every language

모든 언어를 위해

Built for real multilingual use, from subtitle line breaks in Korean and Japanese to an interface in 21 languages.

한국어·일본어 자막 줄바꿈부터 21개 언어 인터페이스까지, 실제 다국어 사용을 기준으로 만듭니다.

About 소개

A one-person studio from Korea.

한국의 1인 소프트웨어 스튜디오.

AnyToAny Studio was founded by Jihwan Eom on March 1, 2026, as a bootstrapped sole proprietorship in South Korea. SubLive is our first product. It is in development and has not launched on the App Store yet.

엄지환이 2026년 3월 1일 대한민국에서 개업한 1인 개인사업자로, 외부 투자 없이 운영합니다. 첫 제품 SubLive는 개발 중이며 아직 App Store에 출시하지 않았습니다.

We build SubLive with Claude Code. The app itself currently uses Apple's on-device speech recognition and translation and does not call the Claude API. Our next feature, transcript study notes, is being built on the Claude API.

SubLive는 Claude Code로 개발합니다. 현재 앱은 Apple 온디바이스 음성 인식과 번역을 사용하며 Claude API는 호출하지 않습니다. 다음 기능인 자막 학습 노트를 Claude API로 만들고 있습니다.
