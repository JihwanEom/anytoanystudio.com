How we build

만드는 방식

Three principles guide every product we ship.

모든 제품은 세 가지 원칙을 따릅니다.

On-device first

기기 안에서 먼저

Speech recognition and translation run on the phone. No upload, no waiting on a server, and it works offline.

음성 인식과 번역을 휴대폰 안에서 처리합니다. 업로드도, 서버 대기도 없고, 오프라인에서도 동작합니다.

Private by default

기본값은 프라이버시

No accounts, no ads, no tracking. Any future cloud feature will be opt-in and clearly labeled.

계정, 광고, 추적이 없습니다. 앞으로 클라우드 기능을 추가하더라도 사용자가 직접 켜야만 동작하고, 명확하게 표시합니다.

Every language

모든 언어를 위해

Built for real multilingual use, from subtitle line breaks in Korean and Japanese to an interface in 21 languages.

한국어·일본어 자막 줄바꿈부터 21개 언어 인터페이스까지, 실제 다국어 사용을 기준으로 만듭니다.

About AnyToAny Studio

애니투애니 스튜디오 소개

An independent software business in South Korea, founded by Jihwan Eom on February 28, 2026.

엄지환이 2026년 2월 28일 한국에서 시작한 소프트웨어 사업입니다.

One founder, one product

1인 창업, 첫 번째 제품

AnyToAny Studio is a bootstrapped sole proprietorship. Our first product, SubLive, is in development and has not yet launched on the App Store.

외부 투자 없이 운영하는 1인 개인사업자입니다. 첫 제품 SubLive를 개발 중이며, 아직 App Store에 출시하지 않았습니다.

Built with Claude Code

Claude Code로 개발

We use Claude Code during development. SubLive currently uses Apple's on-device speech recognition and translation. It does not yet call the Claude API.

개발 과정에서 Claude Code를 사용합니다. 현재 SubLive는 Apple의 온디바이스 음성 인식과 번역을 사용합니다. Claude API는 아직 연결하지 않았습니다.

Next: transcript study notes

다음 계획: 자막 학습 노트

We plan to use Claude for optional study notes based on transcript text. This feature is not yet available. See the plan or meet our founder.

사용자가 선택하면 자막 텍스트를 Claude로 처리해 학습 노트를 만드는 기능을 계획하고 있습니다. 아직 제공하는 기능은 아닙니다. 개발 계획과 창업자 소개를 확인하세요.
