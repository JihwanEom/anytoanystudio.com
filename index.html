How we build

만드는 방식

Three principles guide every product we ship.

모든 제품은 세 가지 원칙을 따릅니다.

On-device first

기기 안에서 먼저

Speech recognition and translation run on the phone. No upload, no waiting on a server, and it works offline.

음성 인식과 번역을 휴대폰 안에서 처리합니다. 업로드도, 서버 대기도 없고, 오프라인에서도 동작합니다.

Private by default

기본값은 프라이버시

No accounts, no ads, no tracking. Any future cloud feature will be opt-in and clearly labeled.

계정, 광고, 추적이 없습니다. 앞으로 클라우드 기능을 추가하더라도 사용자가 직접 켜야만 동작하고, 명확하게 표시합니다.

Every language

모든 언어를 위해

Built for real multilingual use, from subtitle line breaks in Korean and Japanese to an interface in 21 languages.

한국어·일본어 자막 줄바꿈부터 21개 언어 인터페이스까지, 실제 다국어 사용을 기준으로 만듭니다.
