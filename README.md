# anytoanystudio.com

AnyToAny Studio (애니투애니 스튜디오) 웹사이트. GitHub Pages로 배포한다.

| 경로 | 내용 |
|---|---|
| `/` | 회사 소개 |
| `/sublive/` | SubLive 제품 소개 |
| `/sublive/privacy/` | SubLive 개인정보처리방침 (App Store 개인정보처리방침 URL) |
| `/sublive/support/` | SubLive 지원·FAQ (App Store 지원 URL) |

모든 페이지는 영어/한국어를 함께 담는다. `data-lang="en"`/`data-lang="ko"` 요소를 `assets/site.js`가 전환한다.

로컬 미리보기: `python3 -m http.server 8000` 후 http://localhost:8000
